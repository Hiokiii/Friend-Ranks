# Deadlock Mods

Monorepository for my Deadlock mods.

## Mods

| Mod | Description | Download |
| --- | --- | --- |
| [Friend Ranks](./Friend-Ranks/) | Adds rank badges and Statlocker shortcuts to player profiles and the post-game scoreboard. | [`pak88_dir.vpk`](./Friend-Ranks/build/pak88_dir.vpk) |
| [Extra FOV](./Extra-FOV/) | Adds an experimental Extended FOV Scale slider to Deadlock's Camera settings. | [`pak87_dir.vpk`](./Extra-FOV/build/pak87_dir.vpk) |

Each mod has its own README with installation instructions, compatibility notes, source files, validation scripts, and build tooling.

## Repository layout

```text
Deadlock-Mods/
|-- Friend-Ranks/
`-- Extra-FOV/
```

The projects are independent. Install only the VPKs you want to use, and keep each VPK in an available numbered slot inside `game/citadel/addons`.
